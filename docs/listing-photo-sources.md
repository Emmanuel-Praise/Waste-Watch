# Marketplace photo sources

The marketplace starter entries use resized Wikimedia Commons photographs,
cached locally under `backend/media/marketplace/`. The photos illustrate the
waste categories; they are not claimed to have been taken at the Bamenda
collection locations. Each source file is available under CC0 1.0.
